A major part of the platform was processing concall documents end to end and making them searchable and usable.

## Pipeline flow

1. Ingest PDFs from cloud storage.
2. Run OCR transcription using Gemini.
3. Generate structured summaries and key points with LLMs.
4. Extract entities and insights relevant for investors.
5. Create semantic embeddings and index them for linking and retrieval.

## Why orchestration mattered

I used Prefect to model retries, dependencies, and observability across stages. That improved operational confidence,
especially when handling variable document quality.

## Practical takeaway

In document intelligence systems, orchestration and failure handling are as important as model quality.
