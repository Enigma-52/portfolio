## Overview

Buildr helps developers create and manage portfolios with minimal setup and persistent hosted delivery.

## What I built

- React frontend for portfolio creation and profile management.
- Firebase Storage and Firestore integration for content and assets.
- Cloud Functions for backend logic and automation.
- UI built for quick onboarding and low-friction publishing.

## Outcome

The product supported 200+ users with a simple publishing flow and reliable hosting model.
