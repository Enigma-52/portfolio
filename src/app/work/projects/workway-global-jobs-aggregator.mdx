## Overview

WorkWay automates collection and serving of job opportunities from external sources for a searchable user experience.

## What I built

- Node.js and Express backend for API ingestion and serving.
- Automated retrieval from Greenhouse Jobs API.
- Data compilation pipeline for large listing volumes.
- Frontend-ready endpoints for scalable listing consumption.

## Outcome

The system has indexed 350,000+ jobs, generated 900,000+ search impressions, and reached viewers from more than 150 countries.
