## Overview

BuildStack is a scalable microservices platform designed to run reliably in production. It uses TypeScript and Node.js
for services, PostgreSQL as the primary relational store, Redis for caching, and Google Cloud Platform for
infrastructure and deployment.

## Key Features

- **Scalable microservices architecture**: Developed a platform of services in TypeScript and Node.js, containerized
  with Docker and deployed on Google Cloud Platform, targeting high uptime and predictable performance.
- **Efficient data access and caching**: Integrated PostgreSQL (via Prisma ORM) for structured data and Redis for
  caching hot paths, significantly improving response times. MongoDB is used for event logging and traceability.

## Technologies Used

- **TypeScript & Node.js**: For building strongly typed backend services.
- **PostgreSQL & Prisma ORM**: For relational data and schema management.
- **Redis**: For low-latency caching of frequently accessed data.
- **MongoDB**: For event logging and operational insights.
- **Docker & GCP**: For containerization and cloud deployment of services.
- **RabbitMQ**: For messaging and decoupled communication between services.

## Outcome

BuildStack demonstrates Rohit Singh's ability to design and implement production-grade backend systems that combine
structured data stores, caching, messaging, and cloud infrastructure. The project showcases experience with
microservices, performance optimization, and practical use of modern tooling in real-world workloads.
