## Overview

BuildStack is a backend-heavy microservices project focused on performance, reliability, and clear service boundaries.

## What I built

- TypeScript + Node.js services with a modular architecture.
- PostgreSQL (Supabase) integration using Prisma ORM.
- Redis-based caching on frequently accessed query paths.
- Event logging support for better operational visibility.
- Containerized deployment setup using Docker on GCP.

## Outcome

The platform was designed for stable production usage with measurable performance improvements from caching and cleaner
service isolation.
