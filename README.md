# Rohit Singh's Portfolio

This portfolio uses a simple, clean, beginner-friendly portfolio template. It supports an MDX-based content system for projects and blog posts, an about / CV page and a gallery.

Magic Portfolio was built with [Once UI](https://once-ui.com) for [Next.js](https://nextjs.org).

## Documentation

Docs available at: [docs.once-ui.com](https://docs.once-ui.com/docs/magic-portfolio/quick-start)
